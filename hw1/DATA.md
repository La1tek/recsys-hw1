# Данные для ДЗ-1

**Кривцов Илья Андреевич**

Использую [Steam V2 от авторов SASRec](https://github.com/kang205/SASRec#steam-dataset): отзывы пользователей и описания игр Steam.

- [Отзывы - steam_reviews.json.gz](https://cseweb.ucsd.edu/~wckang/steam_reviews.json.gz)
- [Метаданные игр - steam_games.json.gz](https://cseweb.ucsd.edu/~wckang/steam_games.json.gz)

В исходном наборе **7 793 069 отзывов**. После очистки и отбора осталось **347 050 взаимодействий, 20 000 пользователей и 3 498 игр**.

Оставляю записи с явным Steam ID, ID игры и корректной датой. Для повторных пар пользователь-игра беру самый ранний отзыв.
Временные границы train, validation и test задаю по квантилям 70% и 85% очищенных уникальных взаимодействий.
По train выбираю до 3500 популярных игр с метаданными и до 20 000 наиболее активных пользователей с хотя бы тремя train-взаимодействиями с выбранным каталогом.
В validation и test остаются те же пользователи и игры; объекты без train-взаимодействий после отбора исключаются.

Запуск из корня репозитория:

```bash
bash hw1/run.sh
```

При первом запуске скрипт скачает данные: архив отзывов занимает около 1,3 ГБ. Сами данные в Git не загружаются.
Подготовка данных, протокол оценки и результаты подробно разобраны в [experiments.ipynb](experiments.ipynb).
